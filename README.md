 ### 🌟 核心特性
 * ⚡ 全自动档：输入框失去焦点即刻静默保存，彻底告别“保存”按钮。
 * 🛡️ 优雅托管：认证成功后直接关窗，内核程序（witautonet）在后台常驻守护，不占任务栏。
 * 🔍 状态自愈：深度识别 `-210`（已登录）等状态码，UI 智能切换提示，无需二次操作。
 * 🚀 开机自启动：一键注册系统自启动（针对后台内核），开机即联网，全程无弹窗骚扰。
 * 🧹 内存防护：自动监控并滚动清理控制台日志，防止长时间挂机爆内存。
 * 🎨 颜值在线：内置 Ubuntu Sans Mono 字体，适配 Win11 现代圆角审美。
 
 ---
 
 ### 💻 运行环境
 * 操作系统：Windows 11 x64 (推荐) / Windows 10 (理论兼容)
 * 核心依赖：`witautonet.exe` (需位于同级目录)
 * 资源依赖：`UbuntuSansMono-Regular.ttf` (需位于同级目录)
 
 ---
 
 ### 🛠️ 构建指南
 
 #### 1. 内核程序编译 (需安装 g++)
 > g++ witautonet.cpp -o witautonet.exe -lws2_32 -O3 -mwindows
 
 #### 2. 安装封装工具
 > pip install PyInstaller
 
 #### 3. Python 最终打包

    python -m PyInstaller --noconfirm --onefile --windowed --add-data "witautonet.exe;." --add-data "UbuntuSansMono-Regular.ttf;." --name "校园网一键助手" --distpath "." installer.py
